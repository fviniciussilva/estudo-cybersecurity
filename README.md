# 🛡️ Projeto CyberShield: Trilha Autodidata em Cibersegurança

> "Hacking the learning process." 

Bem-vindo ao repositório do **Projeto CyberShield**. Este não é apenas um repositório de códigos, mas a documentação de uma jornada de aprendizado autodirigido em Segurança da Informação e Ethical Hacking.

## 💡 Sobre o Projeto e a Metodologia (Vibe Coding)

Este projeto nasceu da vontade de democratizar o meu próprio acesso ao conhecimento avançado. O currículo base (`cybershield-curso.html`) foi construído do zero ao avançado através de Engenharia de Prompts e interações guiadas com Inteligência Artificial. 

Em vez de depender de cursos caros e inacessíveis, utilizei a IA para atuar como minha mentora, adaptando os desafios de cibersegurança para a minha base atual como estudante de Análise e Desenvolvimento de Sistemas. Este repositório servirá como meu laboratório para documentar resoluções de CTFs (Capture The Flag), scripts de automação, testes de penetração em ambientes controlados e anotações teóricas.

## 👨🏽‍💻 Motivação Pessoal

Sempre tive o sonho de infância de entender como os sistemas funcionam por debaixo dos panos — a verdadeira essência da mentalidade hacker. Vindo de uma realidade financeira difícil, o acesso à educação formal demorou, e iniciei minha faculdade de tecnologia aos 30 anos. 

O CyberShield é a prova de que a falta de recursos não limita a vontade de aprender. O primeiro sistema que eu "hackeei" foi o meu próprio método de ensino.
